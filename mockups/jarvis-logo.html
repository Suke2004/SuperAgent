Jarvis — mark & thinking state

Four candidate marks, each built to double as the thinking animation the way Claude's ✳ does: one glyph that sits still next to a finished answer and comes alive while the model works. Every mark is a single SVG in currentColor, so the same file serves the app icon, the assistant glyph in a message, the tab bar, and the splash.

Hover isn't needed — the thinking row at the bottom of each card is animating live.

Rate limited · retry in 4s

Idle is dead still — motion means work is happening, so a static glyph is information. Thinking runs the wave outward. Writing holds the glyph still and moves the caret instead, so two animations never compete. Failed breaks the arms into dashes and turns red. Reduce-motion swaps the wave for a simple opacity fade on the core.
